# CODE ROT – Folge 5: MOSSAD (Israel)

**Thema:** Die Ergreifung Adolf Eichmanns in Buenos Aires, 11. Mai 1960. Ich-Perspektive als Mossad-Agent.

**Hook im aggressiven Schnitt:** „15 Jahre versteckt. Dann: *ein* Bus.“

**Wende:** Gefunden hat ihn kein Agent, sondern ein fast blinder Mann, dessen Tochter mit Eichmanns Sohn ausging.
Der Vater nannte sich Klement, der Sohn hieß immer noch Eichmann – verraten von seinem eigenen Namen.
