# CODE ROT – Folge 4: BLOQUE DE BÚSQUEDA (Kolumbien)

**Thema:** Die Jagd auf Pablo Escobar, Medellín, 2. Dezember 1993. Ich-Perspektive als Mitglied des Suchblocks
(Bloque de Búsqueda) der kolumbianischen Nationalpolizei.

**Hook im aggressiven Schnitt:** „Ein Anruf. Zu *lang*.“ über der Flucht über die Dächer.

**Wende:** Gefunden hat Escobar kein Spion, sondern der *Sohn* deines Obersts (Funkpeilung). Verraten hat ihn ein Anruf
bei *seinem* Sohn. „Zwei Väter. Zwei Söhne.“ Und wer den letzten Schuss abgab, weiß bis heute niemand.
